# JitterFX

Herramienta web de animación (Jitter / Hand-drawn) diseñada para artistas digitales y fotógrafos, optimizada para su uso en Twitter (X).

## 🚀 Uso de la Aplicación (Usuarios)

**NO** necesitas descargar nada de este repositorio. La aplicación funciona 100% en tu navegador web.

Haz clic en el siguiente enlace para abrir la aplicación:
**👉 [https://tolgrim-arch.github.io/TOLGRIM-JitterFX/](https://tolgrim-arch.github.io/TOLGRIM-JitterFX/)**

---

## 💻 Detalles Técnicos (Desarrolladores)

JitterFX es una *Progressive Web App* (PWA) de código abierto que procesa deformaciones a nivel de malla mediante WebGL y genera archivos exportables (GIF/WebM) de manera local en el cliente.
